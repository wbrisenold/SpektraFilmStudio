# Photographer workflow

## Import and organize

Import Photos immediately opens the browser. Import Folder/Card requests a folder. Use the optional advanced sheet for reference, verified primary/backup copying, Lightroom Classic or cloud-library work; it requests the source first and keeps storage decisions on one screen. Preserve originals and verify backups before relying on a new archive.

Use folders, albums, search and sort in Library. Highlighted photos, pick/reject flags, ratings, client picks and export selections serve different purposes. Batch actions apply to the highlighted set.

## Cull

Review Single Photo, Compare or Overview. Analyze adds focus, exposure, face and burst information. Best Picks suggests distinct frames inside the chosen folder without deleting files or overriding rejects. Review people groups manually.

## Develop and film

In Edit, keep RAW, FILM and MASK separate. RAW prepares camera white balance, exposure/tone, geometry and optics. Film controls stock, negative/development, printing/scanning, grain, diffusion and density. Controls have reset actions and help. Use presets as starting points, then adjust the photograph.

## Masks and diagnostics

Choose a subject/person/skin mask, click an object or draw a gradient/brush. Select the desired local edit target before adjusting it; return to the global image for global changes. SAM 2.1 Tiny handles object hover, clicks, boxes and brushes; hold Option to subtract. Apple Vision handles foreground, people and face parts. Optional SAM 3 supplies landscape and additional people parts; Depth Anything supplies estimated depth and ViTMatte recovers strands. Install optional models in Settings → Models. Masks persist with recipes, and Update AI Masks or Refine Edges can refresh them. Object selection may select a part such as a door rather than an entire vehicle; add selections as needed.

Scopes, clipping, False Color and skin overlays are monitoring aids. Toggle them when useful; they are excluded from normal exports. Interactive previews use proxies, while settled/export rendering uses the accurate path.

## Optional client proofs

Create a gallery from picks, choose local or configured internet sharing, optionally set a password and limit, then retrieve client selections. Keep client picks distinct from your own flags/export queue. Test external connectivity before sending a link.

## Export and finishing

Select the delivery photos. Open Export settings and choose the output folder once in Destination, then format, dimensions, fit/crop, color space and metadata. Check filename preflight and the preview before Export. Stop cancels work; interrupted jobs retain recovery information. For a single photo, use Export This Photo from Edit.

Photoshop portrait retouching remains a separate application. Export a suitable TIFF/JPEG for that finishing step. Save the Spektra project so non-destructive settings remain editable.
